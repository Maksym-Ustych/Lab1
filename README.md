# Практична робота №1

## Опис роботи
У межах практичної роботи створено програму у середовищі Visual Studio 2022 з використанням Windows Forms.

У програмі реалізовано:
- виведення повідомлення «Моя перша програма!!!»;
- обчислення математичного виразу за заданими значеннями;
- відображення отриманого результату;
- кнопку для завершення роботи програми.

## Середовище розробки
- Visual Studio 2022
- C#
- Windows Forms
